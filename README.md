# 🏭 **SQL-data-warehouse-project**
> A guided implementation of a modern SQL Data Warehouse following the Medallion Architecture (Bronze, Silver, Gold) using Microsoft SQL Server.

--
#📌 **Project-Overview**
> This project demonstrates the end-to-end implementation of SQL Data Warehouse.

> The project was completed by following a structured industry-focused tutorial and implementing every step independently to gain practical
experience in SQL development, data warehousing, ETL concepts, data modelling, and business-ready analytical tables.

> Rather than only learning SQL syntax, this project focuses on understanding how data flows from raw sources into business-ready analytical tables.


---🎯 **Learning-Objectives**
> Understand Data Warehouse concepts.
> Learn the Medallion Architecture.
> Build Bronze, Silver and Gold layers.
> Perform data cleansing and transformation.
> Design business-ready analytical tables.
> Write optimized SQL queries.
> Understand real world data engineering workflow.
> Practice Git and GitHub project management.
